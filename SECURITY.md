# Security Policy

## Supported Versions

Only the latest updates and files on the `main` branch are actively supported with security patches and revisions.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

We take the security of this repository and the resources listed here very seriously. If you find a security issue or vulnerability (e.g., malicious resources, compromised packages referenced in code samples, or data leaks), please do not report it via public GitHub issues.

Instead, please report the vulnerability privately by sending an email to **sharmauday.dev@gmail.com**.

Please include:
1. A detailed description of the vulnerability.
2. Steps to reproduce the issue or details on where the vulnerability resides.
3. Potential impact on learners using the repository.

We will acknowledge your report within 48 hours and work to resolve the issue as quickly as possible. Thank you for helping keep our learning community safe!
