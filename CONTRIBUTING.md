# 🤝 Contributing to AI Roadmap

First off, thank you for considering contributing to the **AI Roadmap**! It's people like you who make this repository an invaluable resource for the global AI developer community.

---

## 🗺️ Quick Contribution Flow

```
[Fork Repo] ──> [Make Changes / Add Resources] ──> [Run Markdown Lint] ──> [Submit Pull Request]
```

---

## 📌 Ways to Contribute
You can contribute in several ways:
1. **Adding Quality Resources**: Found a high-quality free video course or tutorial? Suggest adding it under the respective phase.
2. **Improving Documentation**: Fix typos, improve formatting, add explanatory subheadings or visual flowcharts.
3. **Translating Guides**: Help translate these roadmap documents into other major languages.
4. **Adding New Interview Questions**: Keep our interview preparation materials updated with the latest questions asked at top tech companies.

---

## 📌 Technical Style Guide

### 1. Markdown Formatting
* Maintain consistent naming conventions for file references.
* Keep markdown line length readable.
* Avoid redundant or broken hyperlinks. Run a link checker before proposing changes.
* Use appropriate syntax highlighting for code blocks (e.g., ` ```python `).

### 2. Commit Message Conventions
We follow the **Conventional Commits** standard:
* `feat`: A new feature (e.g., adding a new RAG system design question).
* `fix`: A bug fix or typo correction.
* `docs`: Documentation changes only (e.g., updating roadmap markdown text).
* `style`: Changes that do not affect the meaning of the code (white-space, formatting).

*Example:* `docs: update neural network activation function description in deep learning guide`

---

## 📌 Submission Guidelines
1. Fork the repository and create a new branch from `main`.
2. Ensure you have not introduced any placeholder text or TODOs.
3. Commit your changes with a clear, descriptive message following our commit conventions.
4. Push to your fork and submit a Pull Request to the `main` branch of this repository.
5. Provide a summary of the changes in the PR description, referencing any related open issues.
